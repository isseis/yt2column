# prompts

このディレクトリには、`internal/writer` の `ArticleWriter` が使う既定のプロンプトテンプレートがある。記事の生成のほかに、生成した後の 2 つの段階（字数の調整と検証・推敲）のテンプレートがある。

- `system.tmpl`・`user.tmpl`: 記事の生成
- `shorten_system.tmpl`・`shorten_user.tmpl`: 字数の調整
- `review_system.tmpl`・`review_user.tmpl`: 検証・推敲

6 つのファイルはビルド時にバイナリへ埋め込まれ（`prompts.go`）、実行時にこのディレクトリは要らない。`system.tmpl`・`user.tmpl` の文面は、タスク 0008 の評価で決めた最終の版（[docs/tasks/0008_column_prompt/v5/](../docs/tasks/0008_column_prompt/v5/)）である。評価と、その構成で起こりうる記事の誤りや欠け（製品の制約）は、0008 の評価記録 §6 にある。

本書は、既定のテンプレートの代わりに使う上書きファイルを書く利用者向けの仕様である。上書きファイルは system 用と user 用のそれぞれについて任意に指定でき、指定しなかった側は既定のテンプレートを使う。上書きファイルは `ArticleWriter` の構築時に 1 回だけ読む。既定のテンプレートにも、本書の規則を同じように適用する。

## 書式

テンプレートの構文は Go の [`text/template`](https://pkg.go.dev/text/template) である。ただし、使える構文は後述のものに限る。値はテンプレートとして解釈されず、エスケープもされずにそのまま埋め込まれる（字幕に `{{.Title}}` という文字列があっても、その文字列がそのままプロンプトに入る）。

## 参照できる値

テンプレートから参照できる値は、テンプレートの組ごとに次のとおりである。3 組はそれぞれ別のデータ型で検査され、ある組の値は別の組のテンプレートから参照できない。

- `system`・`user`: 記事の生成
- `shorten-system`・`shorten-user`: 字数の調整
- `review-system`・`review-user`: 検証・推敲

## 生成のテンプレートで参照できる値

`system.tmpl`・`user.tmpl` から参照できる値は次の 4 つだけである。

| 名前 | 値 |
|---|---|
| `.Title` | 動画タイトル |
| `.ChannelName` | チャンネル名 |
| `.Description` | 概要欄 |
| `.Transcript` | 字幕本文。字幕の各区間の文章を、順に改行 1 つで連結したもの。タイムスタンプは含まない |

## 字数の調整のテンプレートで参照できる値

`shorten_system.tmpl`・`shorten_user.tmpl` から参照できる値は次の 5 つだけである。記事と字数だけを渡し、素材（字幕・概要欄・動画タイトル・チャンネル名）は渡さない。

| 名前 | 値 |
|---|---|
| `.ArticleTitle` | 縮める対象の記事のタイトル。生成の `.Title` とは別である |
| `.ArticleBody` | 縮める対象の記事の本文。出典のブロックを含まない |
| `.BodyChars` | 縮める対象の本文の字数（本文の字数の数え方は下の「字数の数え方」を参照） |
| `.TargetBodyChars` | 縮める目標の字数（3600） |
| `.MaxBodyChars` | 本文の上限の字数（4000） |

## 検証・推敲のテンプレートで参照できる値

`review_system.tmpl`・`review_user.tmpl` から参照できる値は、生成の 4 つに、検証の対象の記事の 2 つを加えた次の 6 つである。`.Title` は動画タイトル、`.ArticleTitle` は検証する記事のタイトルである。両方を並べて書いているので取り違えないこと。

| 名前 | 値 |
|---|---|
| `.Title` | 動画タイトル |
| `.ChannelName` | チャンネル名 |
| `.Description` | 概要欄 |
| `.Transcript` | 字幕本文。生成のプロンプトに埋め込む字幕と同じ文字列 |
| `.ArticleTitle` | 検証する記事のタイトル |
| `.ArticleBody` | 検証する記事の本文。出典のブロックを含まない |

## 字数の数え方

本文の字数は、タイトルの行と出典のブロックを除いた本文の、改行を除いたコードポイントの数である。Markdown の記号（`## `・`**` など）と空白は数える。

## 使える関数

text/template の組み込み関数のうち、次のものだけを使える。

`and`・`or`・`not`・`eq`・`ne`・`lt`・`le`・`gt`・`ge`・`len`・`index`

## 使える構文

- テンプレートの地の文と、コメント（`{{/* メモ */}}`）
- 参照できる値の参照（`{{.Title}}`）
- `if`・`else`・`else if`（`{{if .Description}}…{{else}}…{{end}}`）
- 定数（`"文字列"`・`100`・`true`）。文字列の定数は、エスケープを解いた値が正しい UTF-8 であるものに限る
- 括弧による入れ子とパイプライン（`{{if (eq .Title "")}}…{{end}}`・`{{.Title | len}}`）
- 上記の使える関数の呼び出し。引数の数は、パイプラインで前から渡る値も 1 つと数えて、`not`・`len` が 1 個、`ne`・`lt`・`le`・`gt`・`ge` が 2 個、`eq` が 2 個以上、`and`・`or`・`index` が 1 個以上である

条件分岐の中など、展開時に実行されるとは限らない位置にある記述も、構築時に同じ規則で検査する。

## 使えない構文

次の記述を含むテンプレートは、構築時に拒否される。

- 参照できる値以外の参照（`{{.APIKey}}`）と、値のフィールドの参照（`{{.Title.Foo}}`・`{{(.Title).Foo}}`）
- `.` そのもの（`{{.}}`）と変数（`{{$}}`・`{{$.Title}}`・`{{$x := .Title}}`）
- `with`・`range`・`template`・`define`・`block`・`break`・`continue`
- `nil`
- 不正な UTF-8 になる文字列の定数（`{{"\xff"}}`）
- 上記以外の組み込み関数（`print`・`printf`・`println`・`slice`・`html`・`js`・`urlquery`・`call`）
- 引数の数が合わない関数の呼び出し（`{{len}}`・`{{not 1 2}}`・`{{.Title | len .Title}}`）
- 関数の呼び出し以外への引数（`{{.Title 1}}`・`{{"x" 1}}`）と、パイプラインの 2 段目以降に置いた関数の呼び出し以外の値（`{{.Title | .Description}}`）
- 括弧で囲まずに引数に置いた関数（`{{eq len .Title}}`。`{{eq (len .Title) 1}}` と書く）

## 上限

| 対象 | 上限 |
|---|---|
| テンプレート（system 用・user 用のそれぞれ） | 65536 バイト |
| 展開したプロンプト（system・user のそれぞれ） | 1048576 バイト |

プロンプトの上限は、テンプレートが参照する値（特に字幕本文と概要欄）の大きさにも依存する。長い動画では、テンプレートが正しくてもプロンプトが上限を超えて記事の生成が失敗しうる。

## 構築時に拒否されるテンプレート

次のいずれかに当てはまるテンプレートは、構築時に `writer.ErrInvalidTemplate` で拒否される。

- 上書きファイルを読めない（存在しない、権限がないなど）。シンボリックリンクは辿る
- 上書きファイルが通常のファイルでない（ディレクトリ、名前付きパイプ、デバイス、ソケットなど）
- 内容が空、または空白文字だけである
- 正しい UTF-8 のバイト列でない
- 上限を超える
- `text/template` の構文として解析できない
- 使えない構文を含む

構築時の検査は、関数に渡す値の型を確かめない。型の合わない呼び出し（`{{lt .Title 3}}` のように文字列と数を比べるなど）と、値によって起きる失敗（`{{index .Title 100}}` で動画タイトルが 100 バイト以下の場合などの展開時のエラー、展開結果が空白文字だけになる場合、展開結果が上限を超える場合）は、記事の生成時に `writer.ErrInvalidTemplate` で報告される。

## 秘密情報を書かない

テンプレートの文面は、そのままプロンプトとして LLM プロバイダへ送られる。API キーなどの秘密情報をテンプレートに書かないこと。
