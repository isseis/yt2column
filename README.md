# ヨムドウガ for YouTube™

ヨムドウガは、YouTube™ 動画の文字起こしを、新聞・雑誌風の日本語コラム記事に仕立てるブラウザ拡張機能です。話し言葉の脱線や重複を整理し、編集・校正まで行うことで、動画を見なくても論点がすっと頭に入る読み物を目指しました。この拡張機能は無料です。ただし、記事を作る AI のサービスには、利用料がかかります。利用料は、AI を提供する会社（Anthropic 社）に直接支払います。記事はブラウザで読めるほか、ファイルに保存したり、クリップボードにコピーすることも可能です。

> **状態:** 開発の初期段階です。まだリリースしていないので、今は一般には公開していません。公開後の導入手順を、公開に備えて [INSTALL.md](INSTALL.md) にまとめています。

## 特徴

- **結論が先、重要度順に読める構成:** 冒頭のリード文に主題と最も重要な結論をまとめ、本文も重要度順に並べます。新聞記事のように、途中で読むのをやめても動画の大枠をつかめます。
- **動画に合った形式への編集と、文字起こしとの突き合わせ:** インタビュー・対談・レビュー・解説コラムから動画に合った形式を選び、字数を整えたうえで、元の文字起こしと突き合わせて誤字や根拠のない記述をチェックします。
- **画面の変更に強い:** ページを自動操作せず、あなたが選んだ文字起こしだけを受け取るため、YouTube の画面が変わっても安定して使い続けられます。
- **安心して使える設計:** ボタンを押したときだけ対象のページを読み、中継サーバを持たずにブラウザから AI サービスへ直接通信します。ソースコードやプロンプトはすべてオープンソースで公開しています。

## 仕組み

この拡張機能は、動画の文字起こし（音声を文字にしたもの）のうち、あなたが選んだ部分と、動画の情報を集め、Anthropic 社の有料サービスを利用して AI に記事を書かせます。結果はブラウザの専用タブに表示します。

AI が書くので、記事の内容が動画と違うことがあります。大事な内容は、動画で確かめてください。

## 必要なもの

- Chrome 142 以降、または Brave 1.84 以降
- Anthropic 社の API キー（作り方によっては、ワークスペース ID も必要）

API キーは、Anthropic 社の AI を使うためのあなた専用の鍵で、Anthropic 社のサイトで作ります。他人に知られると、あなたの料金で AI を使われてしまうので、パスワードと同様に大切に扱ってください。API キーの作り方によっては、Anthropic 社のサイトで作るワークスペース ID も必要になります。

AI を使うたびに、使った分の料金が Anthropic 社からあなたに課金されます。記事 1 本あたりの費用の目安は約 0.4 米ドルです（選んだ文字起こしが長いほど高くなります）。これは、Claude のチャットの月額契約（claude.ai）とは別の利用料です。

API キーとワークスペース ID の作り方、料金の支払い方、使いすぎを防ぐ設定は、[INSTALL.md](INSTALL.md) にあります。

## インストールと使い方

使い方の流れは、次のとおりです。

1. [INSTALL.md](INSTALL.md) に従って、Anthropic 社で API キーを作り（料金の支払いの準備を含みます）、拡張機能を入れて、API キーを保存します（最初の 1 回だけです）。
2. YouTube の動画のページで、文字起こしパネルを開き、パネルに出ている行を選びます。
3. ブラウザのツールバーにあるヨムドウガのアイコンを押し、記事の生成を始めます。
4. 記事が専用のタブに表示されます。メモ帳などで開ける文章ファイル（Markdown 形式の `.md`）として保存するか、クリップボードにコピーできます。ブラウザを終了すると記事は消えるので、残したいときは、終了する前に保存かコピーをしてください。

入手から最初の記事の保存までの詳しい手順は、[INSTALL.md](INSTALL.md) で説明しています。

## プライバシー

記事を作るために、選んだ文字起こし、動画の URL、動画のタイトル・チャンネル名・概要欄などを Anthropic 社に送ります。あなたの利用であることを示すために、API キーとワークスペース ID も送ります。送った内容は、Anthropic 社のサーバに一定の期間保存されたあと、削除されます。Anthropic 社の説明では、API で送った内容は、既定では AI の学習に使われません。保存の期間などの最新の扱いは、Anthropic 社の説明（[保存の期間](https://privacy.claude.com/en/articles/7996866)、[学習への利用](https://privacy.claude.com/en/articles/7996868)、どちらも英語）で確かめてください。

API キーとワークスペース ID は、使っているブラウザの中にだけ保存します。ただし、同じパソコンに同じユーザーで入っているほかのソフトは、保存した値を読める可能性があります。

作った記事は、あなたが保存を指示しない限り、ファイルとして残らず、ブラウザを終了すると消えます。保存を指示したときは、ブラウザのダウンロードの保存先に入ります。

記事を表示するタブのアドレスには、動画の URL とタイトルが含まれるので、ブラウザの履歴に残ります。ブラウザの履歴の同期を使っていると、ほかの端末にも渡ります。閲覧履歴を読める権限を持つほかの拡張機能からも見えます。
