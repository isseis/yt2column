# yt2column

yt2column は、YouTube の動画を、LLM で雑誌のコラム風の記事にします。拡張を入れたブラウザで動画の文字起こしパネルを開いて字幕の行を選び、ポップアップから生成を始めると、記事がビューアのタブに表示されます。記事は `.md` ファイルに保存するか、Markdown をクリップボードにコピーできます。

> **状態:** 開発の初期段階です。まだリリースしていません。

## 仕組み

記事の生成は、ブラウザの中だけで完結します。拡張は、選んだ字幕と動画の情報を集め、拡張に入れた記事生成モジュール（Go のコードを WebAssembly にビルドしたもの）が、ビューアのタブの中で LLM の API を呼んで記事を作ります。記事の生成のためのサーバもホストも要らず、ブラウザのほかに何もインストールする必要はありません。

拡張が API キーと記事の材料を送る先は、`https://api.anthropic.com` だけです。開発者には何も送りません。

## 必要なもの

- Chrome 142 以降、または Chromium 142 以降の Brave
- Anthropic の API キー

API キーの用意のしかたと、記事 1 本あたりの費用の目安は、[INSTALL.md](INSTALL.md) にあります。

## インストールと使い方

拡張の入手から最初の記事の保存までの手順は、[INSTALL.md](INSTALL.md) にあります。INSTALL.md は、今は日本語だけで書いています。

## プライバシー

**送るもの:** 拡張は、記事の生成のために、選んだ字幕、動画の URL、動画のタイトル・チャンネル名・概要欄を、`https://api.anthropic.com` にだけ送ります。開発者には何も送りません。開発者は、API を中継するサーバを提供していません。

**API キーとワークスペース ID:** このブラウザのプロファイルの `chrome.storage.local` にだけ保存し、ほかの端末へは同期しません。ただし、同じ OS のユーザーとして動くプロセスは、保存した値を読めます。

**記事の生成の記録:** 状態、工程、完成した記事をブラウザのメモリに置き、ブラウザを終了すると消えます。ディスクには書きません。

**ブラウザの履歴:** ビューアの URL は、動画の URL とページのタイトルを持ち、ブラウザの履歴に残ります。履歴はブラウザの同期でほかの端末に渡ることがあり、`tabs` や `history` の権限を持つほかの拡張が読めます。

**細工したビューアの URL:** URL の値を細工したビューアは、利用者を誤解させる見出しやタイトルを表示しうるので、見出しは記事の内容を保証しません。

**記事のファイル:** 記事のファイルは、利用者が保存を選んだときだけ書きます。
