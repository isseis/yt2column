# yt2column

yt2column は、YouTube の動画を、AI で雑誌のコラム風の記事にします。拡張を入れたブラウザで動画の文字起こしパネルを開いて字幕の行を選び、ポップアップから生成を始めると、記事がビューアのタブに表示されます。記事は `.md` ファイルに保存するか、Markdown をクリップボードにコピーできます。

> **状態:** 開発の初期段階です。まだリリースしていません。

## 仕組み

拡張は、選んだ字幕と動画の情報を集め、あなたの API キーを使って Anthropic の AI に記事を書かせます。結果は、ビューアのタブに表示します。

API キーと記事の材料を送る先は、Anthropic（Claude を提供する会社）だけです。

## 必要なもの

- Chrome 142 以降、または Brave 1.84 以降
- Anthropic の API キー

API キーの用意のしかたと、記事 1 本あたりの費用の目安は、[INSTALL.md](INSTALL.md) にあります。

## インストールと使い方

拡張の入手から最初の記事の保存までの手順は、[INSTALL.md](INSTALL.md) にあります。

## プライバシー

**送るもの:** 拡張は、記事を作るために、選んだ字幕、動画の URL、動画のタイトル・チャンネル名・概要欄を、Anthropic にだけ送ります。

**API キーとワークスペース ID:** このブラウザのプロファイルの `chrome.storage.local` にだけ保存し、ほかの端末へは同期しません。ポップアップや Service Worker は、API キーの値を読みません。ただし、同じ OS のユーザーとして動くプロセスは、保存した値を読めます。

**記事の生成の記録:** 状態、工程、完成した記事をブラウザのメモリに置き、ブラウザを終了すると消えます。ディスクには保存しません。

**ブラウザの履歴:** ビューアの URL は、動画の URL とページのタイトルを持ち、ブラウザの履歴に残ります。履歴はブラウザの同期でほかの端末に渡ることがあり、`tabs` や `history` の権限を持つほかの拡張が読めます。

**記事のファイル:** 記事のファイルは、利用者が保存を指示したときだけ保存します。
