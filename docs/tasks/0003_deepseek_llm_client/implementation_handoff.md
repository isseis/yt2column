# 実装への申し送り：DeepSeek アダプタ（LLMClient 実装）

## 本書の位置づけ

[01_requirements.md](01_requirements.md) と [02_architecture.md](02_architecture.md) のレビューで挙がった事項のうち、要件や設計の水準ではなく、実装計画の段階で具体的な手段として扱うべき事項をまとめる。

-   要件定義書は観測できる振る舞いを、アーキテクチャ設計書はコンポーネント・責務・インターフェース・設計判断を定める。設計への申し送りは [design_handoff.md](design_handoff.md) に置く。本書は、それらを満たす具体値・手段と、実装時に踏みやすい落とし穴を記録する。
-   実装計画書は、本書の各項目について採用した手段または扱わない理由を記録する。本書の手段は候補であり、別の手段を選んでもよい。ただし、対応する AC を満たすこと。
-   本書は承認対象の文書ではない。実装時に参照し、項目を追加してよい。

## I-01: 統合テストのタイムアウトの具体値

-   **懸念:** `02_architecture.md` §1.4 の事前調査によれば、DeepSeek の API は混雑時に推論の開始まで最大 10 分待たせうる。統合テストの 1 回の `Generate` のタイムアウトがこれより短いと（当初の案は 5 分、`-timeout` は 15 分）、アダプタが正しく動いていても、AC-24 の正常な生成と打ち切りの確認が `context.DeadlineExceeded` で失敗する。
-   **なぜ重要か:** 正常な混雑で統合テストが失敗すると、アダプタの不具合と見分けられず、料金のかかる再実行を招く。`-timeout` が `Generate` のタイムアウトの合計より短いと、`Generate` の期限より先にテストのバイナリが時間切れで止まり、どの呼び出しで止まったかが分かりにくくなる。
-   **候補:** 1 回の `Generate` のタイムアウトを、待ちの上限 10 分に生成の時間の余裕を足した値（例: 15 分）にする。`-timeout` は、統合テストの中の `Generate` の回数（現在の設計では 2 回）とそのタイムアウトの積に余裕を足した値（例: 2 回 × 15 分に余裕を足して 40 分）にする。`Generate` の回数を変えたときは `-timeout` も見直す。値は実装計画書に記録し、`02_architecture.md` §3.6 の関係（`Generate` のタイムアウト > 待ちの上限 + 生成の時間、`-timeout` > 各 `Generate` のタイムアウトの合計 + 余裕）を満たすことを確認する。
-   **関連:** F-006、AC-23・AC-24。`02_architecture.md` §3.6・§7.2。

## I-02: `make test-integration-deepseek` のコマンドの組み立て

-   **懸念:** `02_architecture.md` の初版は、`go test -tags integration -count=1 -timeout 15m -v -run` の後にパッケージのパスを続けるコマンドを書いていた。`-run` は引数として正規表現を取るため、このまま実装すると `./internal/llm/deepseek` が正規表現として消費され、パッケージの引数がなくなる。その結果、`go test` はカレントディレクトリ（リポジトリのルート）を対象にし、DeepSeek の統合テストは実行されない。
-   **なぜ重要か:** ターゲットが成功しても、料金を払って確認したいはずの統合テストが 1 件も走らない。AC-23 は「少なくとも 1 件のテストが実際に実行されたこと」を `-v` 出力で確認できることを求めており、これを満たさない。
-   **候補:** `-run` を使う場合は、統合テストの関数名に一致する正規表現を必ず渡す（例: `-run '^TestIntegration'`）。`./internal/llm/deepseek` の `integration` タグのテストがすべて統合テストであるなら、`-run` を省いてパッケージのパスだけを渡してもよい。どちらの場合も、`-tags integration`・`-count=1`・`-v`・I-01 の `-timeout` を付ける。実装後に一度実行し、`-v` 出力に統合テストの `=== RUN` と `--- PASS`（またはオプトインの欠如による `--- SKIP` ではないこと）が現れることを確認する。
-   **関連:** F-006、AC-23。`02_architecture.md` §7.2。
