## I-01: 環境変数を読む標準ライブラリの関数の走査範囲

-   **事項:** AC-09 の走査は、プロセスの環境変数を読む標準ライブラリの関数をすべて対象にする必要がある。`os.Getenv`・`os.LookupEnv`・`os.Environ` だけでなく、`os.ExpandEnv`（内部で `os.Getenv` を呼ぶ）、`syscall.Getenv`・`syscall.Environ` なども含む。
-   **理由:** 対象を一部の関数に限ると、たとえば利用者が与えたパスを `os.ExpandEnv` で展開するコードは、`$DEEPSEEK_API_KEY` を含むパスから秘密情報を `internal/config` の外で読める。このコードは変数名の文字列を直接書かないため、秘密情報の変数名の文字列の検査も通り抜ける。
-   **方法の候補:** テストの中で対象の関数を列挙し、なぜその関数が対象か（内部で環境変数を読むこと）をコメントで示す。あるいは、`depguard` や `forbidigo` などの lint の規則で、許可した場所以外での参照を禁止する。どちらの場合も、対象の関数を 1 つ外すと失敗することを、実装を壊して確かめる。
-   **関連:** F-002・AC-09
