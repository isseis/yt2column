# 設計への申し送り：0056 変更履歴のない承認済みの文書の過去の承認

要件定義（[01_requirements.md](01_requirements.md)）の作成中に挙がった、設計で決める事項。`02_architecture.md` は、項目ごとに採った方法、または当てはまらない理由を記録する。

- **H-01: 写した承認の行の書式と印の文言（AC-06・AC-07）。** issue #621 は例として `- <Review date> 承認（<Reviewer>、旧規則）` を挙げている。通常の承認の行（`- YYYY-MM-DD 承認（<承認者>、#<PR 番号>）`。`docs/dev/conventions/requirements_process.md:157-165`）とどれだけ形をそろえるか、印の文言、規則の「Change history」の行の表と例にどう加えるかを決める。印が `#未記入` や `#<数字>` と紛れず、`/runpr` の PR 番号の書き足し（`.claude/commands/runpr.md:228-235`）の対象にならないことも確かめる。
- **H-02: 用語と節の見出しの扱い（AC-01・AC-11）。** 規則の「Documents written under the old rule」の定義は、`Comments` が `-` でない文書を指している（`requirements_process.md:203-208`）。対象を変更履歴のない文書に広げると、作ったばかりの `draft` の文書もこの定義に入る（AC-04 では何も起きない）。見出しと用語を残すか改めるかを決める。改めるなら、規則の中の参照（同書 32、41、46、144、198、267 行）と対象のコマンドの定義の参照（`runpr.md:224`、`fixpr.md:469-470`・`505`、`runplan.md:64`、`mkarch.md:72`、`mkplan2.md:107`）の書き換えも含める。
- **H-03: 写したことの機械的な確かめ（AC-10・AC-12）。** 移した項目は、`git diff` から取り出して `cmp` で比べる（`requirements_process.md:219-224`、`fixpr.md:502-512`）。写した承認の行の日付と承認者を、削除された状態表の行（`Review date`・`Reviewer`）の値とどう比べるかを決める。`fixpr.md` の移し替えの確かめは、`- 旧規則の Comments：` の項目を加える差分だけを対象にしている（同 503 行）。`Comments` が `-` の文書では写した承認の行だけが加わるので、確かめの対象の決め方も見直す。`/runplan`・`/mkarch`・`/mkplan2`・手作業の取り下げのように、エージェント自身が書く経路で確かめるかどうかも決める。
- **H-04: 止まるときの報告の経路（AC-10）。** `/fixpr` では、文書を書き換えるのは修正のサブエージェントで、移し替えの確かめは本体のセッションが行う（`fixpr.md:467-472`・`502-512`）。値が `-` または空のときに、どちらが判定し、作業ツリーをどの状態で残し、何を報告するかを決める。`/runpr` の PRE_MERGE（承認の記録）は `draft` の文書だけを扱うので、写した承認の行を作らない（AC-09）。このことを確かめる。
- **H-05: 中断の後の再実行（AC-05）。** 移し替えは、変更履歴を作るのと同じコミットで行う。途中で中断し、変更履歴だけがある状態で再実行した場合に、文書が「変更履歴のある文書」と判定されて写した承認の行が抜けないかを確かめる。0053 の H-04（`runpr.md` の PRE_MERGE の「既に記録したものは除く」）と同じ観点で、二重に書かない判定も確かめる。
- **H-06: 確かめの方法。** AC-01〜AC-12 は規則とコマンドの定義の文言なので、PR のレビューで読んで確かめる（`manual`）想定である。AC-13 は変更の前後の関係なので、`_checks/` の diff の確かめの候補になる（0053 の `docs/tasks/0053_status_comments_policy/_checks/task_docs_unchanged.sh` が先例）。文書の文言を照合する恒久のテストは加えない（`CLAUDE.md`「Document tests check values, structure, and executable examples, never prose」）。
