### 2.8. 項目 8：現在の push の制限下で Sourcery AI が PR ブランチへ push できるか

-   **リポジトリの ruleset（API 実測、2026-11-24）:** `repos/isseis/yt2column/rulesets/26400325`（`Restrict branch creation/updates`）は `enforcement: "active"`、`target: "branch"`、`conditions.ref_name` は `include: ["~ALL"]`・`exclude: ["refs/heads/main"]`、`rules` は `[{"type": "update"}, {"type": "creation"}]` である。`bypass_actors` は `[{"actor_id": 5, "actor_type": "RepositoryRole", "bypass_mode": "always"}]`（Repository Admin ロール）のみであり、GitHub App（`Integration`）は 1 つも含まれていない。
-   **Sourcery AI の権限と UI 機能:** 公式文書（`https://docs.sourcery.ai/`、2026-11-24 確認）によれば、Sourcery GitHub App はインストール時に `code`（repository contents）・`workflows`・`actions`・`checks`・`commit statuses`・`issues`・`pull requests` の read & write 権限を要求する。一方、PR #1094 の行コメント 11 件を検査したところ、CodeRabbit の「Fix comments」のような Bot 名義でブランチへ直接 push を起動するチェックボックスや autofix リンクは 0 件であった（インライン提案は GitHub 標準の suggestion を利用者が UI から適用する方式）。
-   **制限の効果と未実測の範囲:** GitHub の ruleset 仕様上、`bypass_actors` に含まれない GitHub App は `contents: write` 権限を持っていても保護対象ブランチへの `update`・`creation` を拒否される。ただし、Bot 名義の push を引き起こすトリガー UI が見当たらず予算も超過していたため、実 PR 上で Bot による push を試行して拒否を確認する実測は行っていない。2026-11-24 に利用者と確認し、ruleset `26400325` の API 検証結果をもって設計へ進む合意を得た。

### 2.9. 項目 9：レビュー完了後のスレッド返信（メンションなし）への応答

-   PR #1092（5 件）・#1094（11 件）・#1096（9 件）・#1097（1 件）・#1098（4 件）の計 30 件の `/fixpr` 返信（`User` `isseis`、メンションなし、返信直後にスレッド解決）について、GraphQL `reviewThreads.comments` と `reactions`、および返信後の `pulls/<n>/reviews`・`checkRuns` を確認した。
-   **結果:** 30 件すべてに対し、`sourcery-ai[bot]` は **`THUMBS_UP` リアクション（👍）のみ**を付けた。返信コメント・新規 PR レビュー・新規 CheckRun は 1 件も作られなかった。
-   **公式文書（`https://docs.sourcery.ai/`、2026-11-24 確認）:** Sourcery が開始したスレッド内の返信はコマンドでなくてもチャットとして解釈され、内容（質問など）によってはスレッド内へ返信コメントを投稿しうる。`/fixpr` の返信は解決とセットの対応報告であるためリアクションのみに留まったとみられるが、完了の印と紛れる CheckRun は作らない。

### 2.10. 項目 10：`AGENTS.md`・`CLAUDE.md` を読むか（公式文書）

-   公式文書（`https://docs.sourcery.ai/`、2026-11-24 確認）によれば、Sourcery AI はリポジトリのエージェント指示ファイル（`CLAUDE.md`・`AGENTS.md` 等）の規約・アーキテクチャ方針を参照して PR レビューを行う（Web ダッシュボードの Review Rules と併用可能）。なお `AGENTS.md` のガードテスト（`TestAgentsCodeReviewRules`）が守る `## Code Review Rules` は CodeRabbit と合わせて引き続き有効である。

### 2.11. 補足観測：リポジトリの CI チェックと外部レビュアー CheckRun の識別（H-06 用）

PR #1101 の `head` コミット（`168c9da1`・`b362fe23`）で `gh pr checks --json name,state,bucket,workflow,link` および REST/GraphQL の `checkSuites`・`checkRuns` を観測した。
