# 設計への申し送り（0093）

要件定義の段階で挙がった、設計（`02_architecture.md`）で決める事項。`02_architecture.md` は、各項目にとった方針か、当てはまらない理由を記録する。

## H-01: 道具の出力の形と `--protocol` の番号

**懸念:** 行ごとの急ぎの度合い、番、文書、進み具合（AC-18）を、道具の出力（`internal/chief/output.go` の `RowOutput`）にどの名前と値で加えるかは決まっていない。`/chief` の定義と道具は `--protocol` の番号で版を照合する（`.claude/commands/chief.md:52-56`）。

**なぜ重要か:** 出力を変えても番号を変えなければ、古い定義が新しい道具の出力を読み、印を示さない。逆の組み合わせも同じである。

**候補:** 値は ASCII の列挙の名前（たとえば `urgency: now|later|wait`、`turn: human|ai|none`）にし、日本語の表示は定義が対応させる。出力を変えるので番号を上げる。

**関連:** F-006、AC-18・AC-19

## H-02: 送信の記録と transcript から実行中のコマンドを 1 つに決める規則

**懸念:** AC-11 は、送信の記録と Claude Code の transcript の 2 つから実行中のコマンドを決め、1 つに決まらないときは「決まらない」とする。どういうときに「1 つに決まる」とするかは決まっていない。たとえば、chief が `/runplan` を送った後に人が自由な文で質問に答えると、transcript の人の最後の入力はコマンドでなくなる。

**なぜ重要か:** 規則が狭すぎると、ほとんどの行が「実行中」になる。広すぎると、走っていないコマンドを示す。

**候補:** transcript の人の最後のコマンドが、送信の記録より後に入力されたものならそれを使い、そうでなければ送信の記録を使う。どちらが後かを決められないときは「決まらない」とする。OpenCode の pane は送信の記録だけを使う。

**関連:** F-003、AC-11・AC-12、4.2

## H-03: 絵文字の幅と表の列のそろえ方

**懸念:** 🔴・🟡・🟢 は、端末によって 1 文字分にも 2 文字分にも描かれ、表の列がずれうる。

**なぜ重要か:** 列がずれると、一目で見分けるという目的（2.1）を損なう。

**候補:** 印の列を表の最初の列に置き、ずれが後ろの列だけに及ぶようにする。Claude Code の端末で Markdown の表として描かれるときの見た目を、実地の確かめで見る。

**関連:** F-001、AC-01

## H-04: 自動送信の周の行と段階

**懸念:** `tick` は、自動送信を送った周の行を、その場で「実行中」に書き換え、送ったコマンドを `Running` に入れる（`internal/chief/tick.go:85-96`）。段階（AC-10）と急ぎの度合いは、この書き換えの後に決める必要がある。送った後で確かめに失敗した行は、「要確認」に書き換える（同じ箇所）。

**なぜ重要か:** 書き換えの前に決めると、同じ行が「作成待ち」と「実行中」を同時に示しうる。

**候補:** 急ぎの度合い、番、段階を、行の状態と記録が出そろった最後に 1 か所で決める。並べ替え（AC-13）もその後に行う。

**関連:** F-001・F-003・F-004、AC-10・AC-13

## H-05: PR-N の求め方と、0092 の削除の提案との順

**懸念:** AC-07 の「PR-N」は、`origin/main` の計画書で、PR がまだマージされていない最初の PR マーカーの番号である。今の `Plan`（`internal/chief/task.go:483-503`）は、PR マーカーの番号を持っているかを確かめていない。また、AC-05 は 0092 の削除の提案に依る。0092 とこのタスクのどちらが先に実装されるかは決まっていない。

**なぜ重要か:** マーカーの番号を読み違えると、別の PR の段階を示す。0092 が後になると、削除の提案の行の印を、0092 の実装の中で付ける必要がある。

**候補:** PR マーカーの見出しの `PR-N` を、計画書の読み取りで番号として持つ。0092 が先に入ったときは、このタスクで削除の提案の行に印を付ける。このタスクが先なら、0092 の計画書に、AC-05 を満たす手順を足すよう申し送る。

**関連:** F-001・F-003、AC-05・AC-07
