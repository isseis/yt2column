本書は、タスク 0073 の実装の PR-3 が見直した ADR-0005・0006・0007・0011・0027・0028・0031・0033 について、受け持つ ADR ごとに、見直しの前後の記述の対応（対応表）、頼る参照、書き直さずに残した記述を記録する（[設計書](02_architecture.md) 3.7.2「見直しの記録」）。PR の基点は `b633a13858855ec254898bba18cc3a0f45a447a2` で、頼る参照は、そのコミットで差分の確認の `mentions s3` が挙げた名指しから選んだ。前の系列の ADR からの名指し（ADR-0019 から ADR-0005、ADR-0003 から ADR-0018 など）も、同じ出力に含まれる。

対応表の「行き先」が「消した」の行は、正本の文書か出典の文書が同じ内容を持つときだけ使った。規則が同じ ADR の別の節にあるために重複を消した行は、行き先にその節を書いた。見直して変える箇所がなかった ADR はない。PR-1・PR-2 から持ち越した ADR はない（[実装計画書](03_implementation_plan.md) 1.5「持ち越しの一覧」）。
