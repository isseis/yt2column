## 1. 概要 (Overview)

**目的:** 本書は、YouTube の文字起こしパネルからコピーした字幕に、セグメントではない行（チャプターの見出し行とパネルの操作ラベルの行）が混じっていても受理し、その行を読み飛ばしてセグメントだけを組み立てるための要件を定義する。

**背景:**

`internal/transcript` のコピーした字幕のパーサ（`copied_format.go`）は、タスク `0015_copied_transcript_source` で定義した形 A・形 B の書式に合わない行を拒否する。そのため、チャプター付きの動画でパネル全体を選択してコピーすると、次の行が混じって `invalid_transcript`（`400`）で拒否される。

- **チャプターの見出し行。** パネルは、動画のチャプターを、セグメントの間に時刻のない行として差し込む。日本語 UI の形 A では `チャプター 1: オープニング` などの形で現れる（0015 `02_architecture.md` §1.4.1 で `LR6mhKRKX9Q` の `チャプター 2: 通常スピード` を観測）。0015 の設計はこれを拒否し、利用者への案内で見出しを含めないよう求めている（同 §3.2.4・§4.4）。
- **パネルの操作ラベルの行。** パネルの末尾には `動画の時間と同期` のボタンがあり、パネル全体を選択するとそのラベルが最終行として入る（`testdata/2tcCWM-sRBw.transcript_panel.html:3206-3211`）。パネルの先頭には、タイトルの `文字起こし` と検索欄の `文字音声変換を検索`（形 A のパネル）・`動画内を検索`（形 B のパネル）がある。末尾のボタンは、最後のセグメントのすぐ下にあり、選択から外すのが難しい。

**報告された事象:** 動画 `https://www.youtube.com/watch?v=dsuNgos_kxA` の文字起こしを、チャプターの見出し行（`チャプター 1: オープニング` から `チャプター 24: 次回予告` までの 24 行）を含めて送ったところ、サーバが `invalid_transcript` を返した。見出し行を除いた同じ入力は受理される（本要件の作成時に `internal/transcript` のパーサで再現を確認した）。

**方針の変更:** 0015 は、セグメントでない行をすべて拒否し、見出しを含めないことを利用者への案内で求める設計だった。本書は、そのうち **内容から特定できる行**（チャプターの見出し行と、既知のパネルの操作ラベル）だけを読み飛ばし、それ以外のセグメントでない行は引き続き拒否する。位置から見出しを推測して無視する形にはしない（0015 §3.2.9 の方針を維持する）。未知の行を拒否する性質を残すのは、YouTube の UI の変更で書式が変わったことを検出するためである（0015 §1.4.4）。

## 2. 目的とスコープ (Goals and Scope)

### 2.1. 目的 (Goals)

- チャプターの見出し行を、形 A の入力で受理して読み飛ばす（F-001）。
- パネルの既知の操作ラベルの行（末尾の `動画の時間と同期` を含む）を、形 A の入力で受理して読み飛ばす（F-002）。
- 読み飛ばす行以外の、セグメントでない行を拒否する振る舞いを維持する（F-003）。
- 拒否のエラーの契約（`ErrCopiedTranscriptFormat` とその非公開の理由の番兵、値の非包含）を維持する（F-004）。
- 上記を確かめるテストと、必要な実データ・文書を整える（F-005）。

### 2.2. スコープ (In Scope)

- 形 A の入力に混じるチャプターの見出し行の読み飛ばし（F-001）。
- 形 A の入力に混じるパネルの操作ラベルの行の読み飛ばし（F-002）。
- 上記の読み飛ばしと、既存の拒否の振る舞いとの関係（F-003）。
- 拒否のエラーの契約の維持（F-004）。
- 上記を確かめるユニットテスト（F-005）。

### 2.3. スコープ外 (Out of Scope)

- **形 B の入力の扱い。** 形 B の入力を変えない。形 B には、見出しが `チャプター N: タイトル` の接頭辞を持たない素のタイトル（`存在感のある声`・`What is symmetry in physics?` など。0015 §1.4.1）として現れ、内容から見出しと本文を区別できない。形 B の入力を変えないので、形 B のパネル全体の選択（先頭の操作ラベルと末尾の `動画の時間と同期` を含む）は、本タスクの後も `invalid_transcript` で拒否される。形 B の扱いは将来のタスクとする。
- パネル以外の表示項目（動画ページの `タイムライン` など）の読み飛ばし。これらはセグメントでない行として引き続き拒否する。
- パーサが受理する形 A・形 B の書式（時刻の文法、読み上げ用ラベル、行の区切り、本文の規則）の変更。0015 のままとする。
- 拡張（`extension/`）の変更。拡張は選択範囲を `window.getSelection().toString()` のまま送り、行を除去しない（0015 §1.4.3、[security.md](../../dev/security.md) §8.1）。
- サーバ（`internal/server`）の拒否の理由と応答の形式の変更。
- `transcript.Transcript`・`Segment`・`TranscriptSource` の型の変更。

## 3. 機能要件 (Functional Requirements)

### 3.1. 機能一覧

#### F-001: チャプター見出し行の読み飛ばし（形 A）

形 A の入力を解析するとき、行が次の**見出しの形**に一致する場合、その行をチャプターの見出し行として読み飛ばす（セグメントを作らない）。読み飛ばした行は、セグメントの数・`StartMs`・`Text`・順序に影響しない。

**決定（見出しの形）:** 1 つの行の全体が、次のいずれかに一致することを要する。数字は ASCII の `0`〜`9` だけを使う。

| 表示言語 | 形 |
|---|---|
| 日本語 UI | `チャプター` + U+0020（1 つ）+ 正の整数 + `:`（ASCII）+ U+0020（1 つ）+ タイトル |
| 英語 UI | `Chapter` + U+0020（1 つ）+ 正の整数 + `:`（ASCII）+ U+0020（1 つ）+ タイトル |

-   正の整数は先頭に `0` を付けない（`[1-9][0-9]*`。`0` と `01` は見出しの形に一致しない）。
-   タイトルは 1 文字以上で、空白文字だけではない。タイトルの先頭・末尾に空白文字を含めてよい。タイトルの途中の `:`・空白・`チャプター` などの語を含めてよい。タイトルは行末までである。
-   行の先頭・末尾の空白文字を許さない（形 B の時刻の行と同じく、前後に空白文字のある行は見出しの形に一致しない）。行全体の制御文字の検査（0015 §3.2.1）は見出しの形にも適用する。
-   見出しの語（`チャプター`・`Chapter`）の言語は、読み上げ用ラベルの言語の固定（0015 §3.2.4）に影響しない。見出しの語の言語と、入力で固定したラベルの言語が一致することを要さない。見出し行は入力の言語の判定に使わない。
-   見出し行は、入力の先頭の行でも、セグメントの間の行でも、入力の末尾の行でもよい。
-   英語 UI の `Chapter` は観測していない。英語 UI の読み上げ用ラベル（0015 §1.4.1 で `24 seconds` などを観測）を受理するのと同じ規則として受理する（0015 §3.2.8 と同じく、理由のある未観測の形）。実物での確認を §7 に記す。

**決定（観測していない見出しの形）:** 上記の形に一致しない見出しの表記（全角コロン `：`、区切りの空白がない `チャプター2: タイトル`、番号のない `チャプター: タイトル`、`チャプター 2 タイトル`、英語 UI の `chapter 2: title` など）は、見出しの形に一致しないので、F-003 により拒否する。観測していない表記を推測で受理しない（0015 §1.4.4 と同じ方針）。

**Acceptance Criteria**:
- **AC-01**: 日本語 UI の見出し行（`チャプター 1: オープニング`・`チャプター 2: たった1か月半で1億1481万件の漏洩`）がセグメントの間にある形 A の入力を解析すると成功する。返る `Segments` は、同じ入力から見出し行を取り除いた入力の `Segments` と、要素の数・各要素の `StartMs`・`Text`・順序がすべて等しい。
- **AC-02**: 見出し行のタイトルの文字列が、返るどの `Segment.Text` にも含まれない。`Segments` の要素の数は、入力のうち時刻で始まり本文を持つ行の数に等しい。
- **AC-03**: 入力の先頭の行がチャプターの見出し行のとき、その行は読み飛ばされ、読み上げ用ラベルの言語はその次のセグメントの行で固定される。先頭の行が日本語 UI の見出しで、最初のセグメントの行が英語 UI のラベル（`0:000 secondsHello` など）でも受理する。
- **AC-04**: 見出しの形に一致しない行（`チャプター: タイトル`・`チャプター 0: タイトル`・`チャプター 01: タイトル`・`チャプター2: タイトル`・`チャプター 2 タイトル`・`チャプター 2: `（タイトルが空白だけ）・英語 UI で `chapter 2: title`）は、読み飛ばさずに拒否する。
- **AC-05**: 見出し行だけで本文のあるセグメントが 1 つもない入力（例: `チャプター 1: オープニング\n`）は、`ErrCopiedTranscriptFormat` を包むエラーで拒否する（本文のあるセグメントがない。0015 §3.2.6）。
- **AC-06**: タイトルに `:`・空白・`チャプター` を含む見出し行（例: `チャプター 5: なぜこんなに漏れるのか？`・`チャプター 12: 目には目を、AIにはAIを`）を受理し、読み飛ばす。

#### F-002: パネルの操作ラベルの行の読み飛ばし（形 A）

形 A の入力を解析するとき、行の全体が、下の**操作ラベルの一覧**のいずれかの文字列と完全に一致する場合、その行をパネルの操作ラベルとして読み飛ばす（セグメントを作らない）。

**決定（操作ラベルの一覧）:** 次を、`testdata/2tcCWM-sRBw.transcript_panel.html` と 0015 の観測（§1.4.1）に基づいて定める。

| 表示言語 | ラベル | パネルでの位置 | 出典 |
|---|---|---|---|
| 日本語 UI | `文字起こし` | パネルのタイトル（先頭） | `transcript_panel.html:29`・`:33` |
| 日本語 UI | `文字音声変換を検索` | 形 A のパネルの検索欄（先頭） | `transcript_panel.html:127`・`:128`、0015 §1.4.1（検索欄 `文字音声変換を検索`＝形 A） |
| 日本語 UI | `動画内を検索` | 形 B のパネルの検索欄（先頭） | 0015 §1.4.1（検索欄 `動画内を検索`＝形 B） |
| 日本語 UI | `動画の時間と同期` | パネルの末尾のボタン | `transcript_panel.html:3206`・`:3211` |
| 英語 UI | `Search transcript` | 形 A のパネルの検索欄（先頭） | 0015 §1.4.1（検索欄 `Search transcript`＝形 A） |

**決定（観測していない操作ラベル）:** 上の表の `Search transcript` は 0015 §1.4.1 で観測したものである。それ以外の英語 UI の操作ラベル（パネルのタイトル `Transcript`・末尾のボタン `Sync to video`・形 B の検索欄 `Search in video` など）は観測していない。観測していない文字列を推定で一覧に加えない（0015 §1.4.4）。実物が得られた時点で 02 で一覧に加える（§7）。このため、英語 UI のパネル全体の選択は、本タスクの後も末尾のボタンなどで `invalid_transcript` になることがある（既知の制限）。

-   一致は行の全体で行う。前後に空白文字のある行、ラベルの一部だけを含む行（例: `動画の時間と同期について話します`）、ラベルに別の文字が続く行は、操作ラベルに一致しない。
-   行全体の制御文字の検査（0015 §3.2.1）は操作ラベルにも適用する。
-   操作ラベル行は、入力の先頭でも、セグメントの間でも、入力の末尾でもよい。
-   操作ラベル行は、読み上げ用ラベルの言語の固定（0015 §3.2.4）に影響しない。

**Acceptance Criteria**:
- **AC-07**: 末尾のセグメントの直後に `動画の時間と同期` の行がある形 A の入力（報告された事象）を解析すると成功する。返る `Segments` は、その行を取り除いた入力の `Segments` と、要素の数・各要素の `StartMs`・`Text`・順序がすべて等しい。`動画の時間と同期` の文字列は、返るどの `Segment.Text` にも含まれない。
- **AC-08**: 先頭に `文字起こし`・`文字音声変換を検索` の行がある形 A の入力（パネル全体の選択）を解析すると成功し、それらの行を読み飛ばす。`動画内を検索`・`Search transcript` の行も同様に読み飛ばす。
- **AC-09**: 操作ラベルと同じ語を含むが一致しない行（`動画の時間と同期について話します`・`文字起こしのコツ`・`動画の時間と同期 `（末尾に空白））は、読み飛ばさずに拒否する（時刻で始まらず、見出しの形にも一致しないため）。
- **AC-10**: 操作ラベル行は読み上げ用ラベルの言語の固定に影響しない。先頭に `文字起こし` の行があり、最初のセグメントの行が英語 UI のラベルでも受理する。
- **AC-11**: 操作ラベル行だけで本文のあるセグメントが 1 つもない入力（例: `文字起こし\n動画の時間と同期\n`）は、`ErrCopiedTranscriptFormat` を包むエラーで拒否する。

#### F-003: セグメントでない行の拒否の維持

F-001・F-002 で定めた行以外の、セグメントでない行は、引き続き拒否する。これは、利用者がパネル以外の文字列を選んだ場合と、YouTube の UI の変更で新しい種類の行が現れた場合を検出するためである。

**決定（`タイムライン` などのパネル以外の表示項目）:** 0015 が拒否の対象として挙げた `タイムライン`・`存在感のある声`・`What is symmetry in physics?` などの行は、F-001・F-002 のどちらにも一致しないので、引き続き拒否する。パネルの操作ラベルに含めない。

**Acceptance Criteria**:
- **AC-12**: 時刻で始まらず、F-001 の見出しの形にも F-002 の操作ラベルの一覧にも一致しない行（`タイムライン`・`存在感のある声`・`What is symmetry in physics?`・`こんにちは`）を含む入力を、`ErrCopiedTranscriptFormat` を包むエラーで拒否する。
- **AC-13**: 未知の新しいラベル（例: `チャプターの一覧`・`Download transcript`）を含む入力を拒否する（書式の変更の検出を残す）。

#### F-004: 拒否のエラーの契約の維持

読み飛ばしを加えても、拒否のエラーの契約を変えない。

**Acceptance Criteria**:
- **AC-14**: F-001〜F-003 のすべての拒否について、返るエラーは `errors.Is(err, ErrCopiedTranscriptFormat)` を満たし、部分的な結果（`nil` でない `[]Segment`）を返さない。`ErrCopiedTranscriptFormat` を包む新しい、`internal/transcript` の外から観測できる番兵エラーを追加しない（静的な確認）。
- **AC-15**: 拒否のエラーの文字列に、入力の字幕の文字列（本文・見出しのタイトル・操作ラベル・時刻）を含めない（0015 AC-06 を維持する）。行番号は含めてよい。

#### F-005: テストと実データ

**Acceptance Criteria**:
- **AC-16**: AC-01〜AC-15 を確かめるユニットテストを加える。テストの入力は、`_test.go` の中の文字列（合成の入力）で作る。報告された入力（動画 `dsuNgos_kxA`）の全体は、再配布の許諾が確認できないため `testdata/` に保存しない（[security.md](../../dev/security.md) §7）。
- **AC-17**: 再配布が許諾されたライセンス（CC BY など）の、チャプター付きの動画のコピーが得られた場合は、`testdata/` に保存し、`testdata/README.md` に出典・ライセンス・取得日・取得方法・加工内容を記録する。得られない場合は、得られなかったことを 02 に記録する。
- **AC-18**: 既存のテスト（`internal/transcript/copied_format_test.go`・`copied_test.go`・`internal/writer/prompt_test.go`・パイプラインの guard）が、本タスクの後もそのまま通る。
- **AC-19**: 報告された動画の入力（チャプター見出し行 24 行を含む形 A）を、実際のサーバと拡張を通して送り、`202` で受理されることを手動で確かめる。結果を 03 に記録する（0011 の手動確認と同じ方法）。
- **AC-20**: サーバの本文の上限と同じ大きさ（4 MiB）の、見出し行と操作ラベル行を含む入力で解析が完走し、解析の時間とメモリが入力の長さに比例する（0015 AC-08 を維持する）。

### 3.2. 信頼できない入力の境界 (Untrusted Input Boundaries)

コピーした字幕は、利用者がブラウザでコピーした外部の値であり、信頼できない入力として扱う。本タスクが変えるのは、形 A の入力で読み飛ばす行の種類だけである。文書全体と行の検査（生バイトの UTF-8、空白だけの入力を拒否、1 つの入力の中の行の区切りの統一、空行と制御文字の拒否、末尾の区切りの数）と、時刻・読み上げ用ラベル・本文の規則は、0015 と `internal/strictjson`（サーバのリクエストの本文）のままとする。

| 境界 | 消費する要素 | 受理する形 | 上限 | 拒否時の扱い | 主な AC |
|---|---|---|---|---|---|
| 形 A の入力のチャプター見出し行 | 行全体（`チャプター`・`Chapter`・番号・`:`・タイトル） | §F-001 の見出しの形に一致する行だけ。一致しない行は読み飛ばさない | 行の長さの上限は本文と同じ。入力全体の上限は 4 MiB | 読み飛ばす（拒否しない）。見出しのタイトルは出力（`Segments`・プロンプト・記事・中間生成物）に含めない | AC-01〜AC-06 |
| 形 A の入力のパネルの操作ラベル行 | 行全体（一覧の文字列） | F-002 の一覧の文字列と行全体が完全に一致する行だけ | 同上 | 読み飛ばす（拒否しない） | AC-07〜AC-11 |
| 形 A の入力のその他のセグメントでない行 | 行全体 | 時刻で始まる行（0015 §3.2.4）。F-001・F-002 に一致しない行 | 同上 | `ErrCopiedTranscriptFormat`（非公開の理由の番兵）。部分的な結果を返さない。値の文字列を含めない | AC-12〜AC-15 |

-   標準ライブラリが黙って修復・正規化すれば受理できてしまう入力は、受理する形を明示的に定めたうえで、それ以外を受理しない。見出しの形と操作ラベルの一覧は、その明示的な形である。
-   読み飛ばす行の内容によって実行する処理を選ばない。読み飛ばすだけで、ほかの解析の振る舞いを変えない。

## 4. 非機能要件 (Non-Functional Requirements)

### 4.1. 性能 (Performance)

-   解析の時間とメモリは入力の長さに比例する（AC-20）。見出し行の判定は、行の先頭の定数文字と数字の比較であり、行の長さに比例する。操作ラベルの判定は、一覧（5 文字列）との比較であり、行の長さと一覧の数に比例する。
-   LLM の呼び出しと `yt-dlp` の呼び出しの回数を変えない。

### 4.2. セキュリティ (Security)

-   読み飛ばした見出しのタイトルと操作ラベルを、`Segments`・プロンプト・記事・中間生成物・ログのいずれにも含めない（AC-02・AC-07）。読み飛ばす行の内容は、解析の振る舞いを選ぶためだけに使う（0015 §1.3.1 の例外 1 の範囲）。
-   拒否のエラーの文字列に、入力の字幕の文字列を含めない（AC-15。[security.md](../../dev/security.md) §6）。
-   報告された入力の全体を `testdata/` に保存しない（AC-16。[security.md](../../dev/security.md) §7）。

### 4.3. 信頼性・可用性 (Reliability/Availability)

-   チャプター付きの動画の、パネル全体の選択が受理され、`invalid_transcript` で拒否されない（AC-01・AC-07・AC-19）。
-   見出し行と操作ラベル行を含まない入力の解析結果を変えない（AC-18）。

### 4.4. 互換性 (Compatibility)

-   `transcript.CopiedSource`・`CopiedInput`・`NewCopiedSource`・`Fetch` のシグネチャと契約を変えない。
-   `ErrCopiedTranscriptFormat` と、非公開の理由の番兵の集合（0015 §4.1）を変えない。新しい、`internal/transcript` の外から観測できる番兵エラーを追加しない（AC-14）。
-   `internal/transcript` の公開の型・関数の集合を変えない。
-   `internal/pipeline` の guard（`TestCommonTypesFieldSets`）が固定する型のフィールド集合を変えない。
-   拡張とサーバの変更を要求しない。

### 4.5. 保守性 (Maintainability)

-   読み飛ばす行の形（見出しの形と操作ラベルの一覧）を、`internal/transcript` の 1 か所に定数として置く。呼び出し側（サーバ・拡張）に同じ規則を持たせない。
-   新しい表示項目が観測されたときに、一覧に 1 行を加えるだけで対応できる形にする。

## 5. 制約条件 (Constraints)

-   [project_overview.md](../../dev/project_overview.md) の「決定済みの方針」「前提・制約」と [CLAUDE.md](../../../CLAUDE.md) に従う。外部ライブラリを追加しない。
-   [CLAUDE.md](../../../CLAUDE.md) の「Reject, don't normalize」に従う。読み飛ばすのは、明示的に定義した見出しの形と操作ラベルの一覧に完全に一致する行だけであり、ほかのセグメントでない行を読み飛ばさない。
-   タスク `0015_copied_transcript_source` の書式の定義（形 A・形 B、時刻の文法、読み上げ用ラベル、行の区切り、本文の規則、禁止の入力の一覧）のうち、本タスクが変えるのは、形 A で読み飛ばす行の種類だけである。それ以外を変えない。0015 の文書は履歴として変更しない（本タスクが上書きする）。
-   拡張（#111）の「選択範囲をそのまま送り、DOM の構造に依存しない」方針を変えない。
-   ユニットテストは、実際の `yt-dlp` も LLM の API も Webhook もブラウザも呼ばない（[CLAUDE.md](../../../CLAUDE.md)「Testing Strategy」）。報告された実データでの確認（AC-19）だけを手動で行う。

## 6. 用語集 (Glossary)

-   **形 A・形 B:** 0015 §3.2.4 と同じ。形 A は 1 セグメントが 1 行で、時刻・読み上げ用ラベル・本文が区切りなしに連結される。形 B は時刻の行と本文の行が分かれる。
-   **セグメントでない行:** 形 A の入力の行のうち、時刻で始まらない行。0015 はすべて拒否する。本タスクは、そのうち見出しの形と操作ラベルの一覧に一致する行を読み飛ばす。
-   **チャプターの見出し行:** 文字起こしパネルが、動画のチャプターを表すためにセグメントの間に差し込む行（0015 §1.4.1）。
-   **見出しの形:** 本書 F-001 で定める、チャプターの見出し行を認識する形（`チャプター`・`Chapter` + 番号 + `: ` + タイトル）。
-   **パネルの操作ラベル:** パネルが持つ、タイトル・検索欄・末尾のボタンのラベル。本書 F-002 で一覧を定める。
-   **読み飛ばす:** その行をセグメントにせず、`Segments` に含めないこと。入力全体を拒否しない。
-   **読み上げ用ラベル:** 0015 §3.2.3 と同じ。日本語 UI の `24 秒`・`1 分 6 秒` と、英語 UI の `24 seconds`。
-   用語は [translation_glossary.md](../../translation_glossary.md) と統一する。

## 7. 未解決の点（レビューで決める）(Open Questions)

- **英語 UI の文字列。** 見出しの `Chapter`（F-001）を対称性で受理する案をレビューで決める。操作ラベルは `Search transcript` だけを一覧に加えた（F-002）。パネルのタイトル `Transcript`・末尾のボタン `Sync to video`・形 B の検索欄 `Search in video` は未観測であり、加えるかどうかと、加えるときの文字列（英語 UI の実物で確認する）をレビューで決める。
-   **先頭の操作ラベルを含めるか。** 報告された事象は末尾の `動画の時間と同期` である。パネルの先頭の `文字起こし`・検索欄のラベルも一覧に含めるか（F-002 は含める案）。選択の始点によっては含まれないので、含めない案もある。
-   **形 B の扱い。** 形 B の見出しは内容から区別できない（§2.3）。末尾のボタンだけを形 B でも読み飛ばすか、形 B は将来のタスクにまとめて委ねるか。
-   **パネル以外の表示項目（`タイムライン` など）。** 読み飛ばす一覧に含めるか、拒否のままにするか（F-003 は拒否のまま）。
