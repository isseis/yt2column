# ADR-0043: クリップボードへのコピーで記事のメンションを無効化し、コピーは拒否しない

## 状態

| 項目 | 値 |
|---|---|
| 状態 | `有効` |

## 背景

利用者は、ビューアで記事を Markdown 形式でクリップボードへコピーし、Slack や Mattermost のチャンネルに手で貼り付けて共有する。記事は LLM の出力で、タイトル・チャンネル名・本文は、字幕と動画メタデータへのプロンプトインジェクションで操作されうる。YouTube のハンドルは `@` で始まるので、概要欄やチャンネル名から `@名前` が記事に入りうる。貼り付けた `@channel`・`@here`・`@名前` は、チャンネル全体や個人への通知になる。

2026-11-11 に、Mattermost のチャンネルへの貼り付けを実機で確かめた（版は記録していない）。`@channel`・`@here`・`@名前` はメンションになり、`@` の直後に U+200B を入れるとメンションにならなかった。コードスパンとフェンス付きコードブロックの中の `@channel`、URL の中の `@`、全角の `＠channel`、`<!channel>`・`<@名前>`・文字参照はメンションにならず、`<https://…|表示>` はメンションでないリンクになった。確かめた並びと結果は [0083 要件定義書](../../tasks/0083_remove_slack_webhook/01_requirements.md)「要件定義の際に決めたこと（2026-11-11）」にある。Slack では確かめていない。

## 決定

-   **コピーする文章では、対象の `@` を、`@` の直後に U+200B を入れて無効化する。** 対象はタイトルの見出しの行、チャンネル名の行、本文のコードの範囲の外である。コードの範囲を判定できない本文では、本文のすべての対象の `@` を無効化する。語の途中の `@` と、直前が `/` の `@`（URL を壊さないため）は変えない。貼り付けた記事がメンションにならないようにするためである。チャンネル名の行を対象にするのは、チャンネル名が外部由来で `@` を含みうるためである。対象の `@` の定義と規則は [security.md](../security.md) §6「信頼できないテキストの取り扱い」と、0083 要件定義書 F-002 にある。
-   **コピーは、記事の内容によって拒否しない。** コードの中の `@`、直前が `/` の `@`、`<!`・`<@`、文字参照、`<a|b>` の形は、そのまま残す。実機の確かめで、どれも貼り付けた後にメンションにならなかったためである。拒否すると、利用者はその記事をコピーできなくなる。規則は 0083 要件定義書 F-002 にある。
-   **無効化した数を、コピーの結果の通知で知らせる。** 1 個以上を無効化したときだけ数を示す。貼り付けた文章が見た目と違う文字を含むことを、利用者が知れるようにするためである。規則は 0083 要件定義書 F-003 にある。
-   **表示・保存するファイル・`--out` のファイルは無効化しない。** 無効化はコピーする文章だけに行う。issue #770 で、表示と `--out` のファイルの内容を変えないと決めたためである。保存するファイルは `--out` のファイルと同じ中身である。規則は 0083 要件定義書 §2.3「スコープ外 (Out of Scope)」と F-002 にある。

この決定は、まだコードと security.md に反映していない。いまのコピーは表示用の Markdown をそのまま書き、security.md §6 は Webhook への投稿の規則を述べる。この差分は [#770](https://github.com/isseis/yt2column/issues/770) の実装で解消する。

## 採らなかった案

-   **Webhook への投稿の拒否の規則（無効化しない並びを含む記事を 1 通も送らない）を、コピーにも残す。** 実機の確かめで、拒否していた並びは貼り付けた後にメンションにならず、拒否するとコピーできない記事が生じる（[0083 要件定義書](../../tasks/0083_remove_slack_webhook/01_requirements.md)「要件定義の際に決めたこと（2026-11-11）」）。
-   **コピーで無効化した数を示さない。** 貼り付けた文章が見た目と違う文字を含むことに、利用者が気づけない（0083 要件定義書「要件定義の際に決めたこと（2026-11-11）」）。
-   **チャンネル名の行を無効化の対象から外す。** チャンネル名は外部由来の値で、`@` を含みうる（0083 要件定義書「要件定義の際に決めたこと（2026-11-11）」）。

## 結果

-   コピーした文章は、表示用の Markdown と U+200B の有無で異なる。貼り付けた後の文章を検索や比較に使うと、U+200B のために一致しないことがある。
-   保存したファイルの中身を貼り付けた場合は、無効化されない。
-   無効化が効くことは、確かめた Mattermost についてだけ言える。Slack と、確かめていない版では保証しない。
-   `<https://…|表示>` の形は、Mattermost に貼り付けるとリンクになる（行き先は `about:blank#blocked` で、メンションにはならない）。

## 経緯

- 2026-11-11 Webhook への投稿の廃止に合わせて、メンションの無効化をビューアのコピーに移した。コピーは拒否せず、チャンネル名の行も対象にし、無効化した数を通知で示す（[0083 要件定義書](../../tasks/0083_remove_slack_webhook/01_requirements.md)「要件定義の際に決めたこと（2026-11-11）」）
