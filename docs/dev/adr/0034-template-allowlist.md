# ADR-0034: プロンプトのテンプレートで使える構文を許可リストで絞り、記事の出典のリンクは LLM ではなくコードで付ける

## 状態

| 項目 | 値 |
|---|---|
| 状態 | `有効` |

## 背景

`ArticleWriter` は、プロンプトの文面をテンプレートとしてコードから分け、既定のテンプレートをバイナリに埋め込んだ。CLI は、開発の経路として、既定のテンプレートの代わりに利用者のファイルを読む（[0004 要件定義書](../../tasks/0004_article_writer/01_requirements.md) §1「概要」、[cli.md](../guides/cli.md) の「使い方」）。localhost サーバは上書きのファイルを読まず、埋め込みのテンプレートだけを使う。

テンプレートには、動画タイトル・チャンネル名・概要欄・字幕本文を埋め込む。テンプレートの構文が自由だと、参照できる値を限ることも、展開でメモリを使い切らないことも、展開する前には確かめられない。`text/template` は、存在しないフィールドの参照を展開したときに初めてエラーにし、試しに展開しても、通らなかった分岐の中の参照は見つからない（[0004 設計への申し送り](../../tasks/0004_article_writer/design_handoff.md) H-02）。

記事の末尾には、必ず元動画へのリンク（出典）を付ける（[project_overview.md](../project_overview.md)「前提・制約」）。字幕・タイトル・概要欄はプロンプトに埋め込まれるので、プロンプトインジェクションで生成結果が操作されうる（[0004 要件定義書](../../tasks/0004_article_writer/01_requirements.md) §1「概要」）。出典のリンクを LLM の出力に任せると、出典が欠けたり別の URL に差し替えられたりしうる。

## 決定

-   **テンプレートで使える構文と関数を、許可リストで絞る。** 参照できる値を限ることと、展開でメモリを使い切らないことを、展開する前に確かめられるようにするためである（[0004 設計への申し送り](../../tasks/0004_article_writer/design_handoff.md) H-02・H-11）。使える構文・関数と使えない構文の一覧は [prompts/README.md](../../../prompts/README.md) の「使える関数」「使える構文」「使えない構文」に従う。
-   **検査は構築時に、解析木のすべてのノードに対して行う。** 既定のテンプレートにも上書きファイルにも同じ検査を行い、展開で通るとは限らない分岐の中も検査する。検査はノードの種類で分岐して許可した種類だけを通すので、Go の新しい版が足した構文も、許可リストに加えるまでは拒否される。規則に反するテンプレートは拒否し、記事の生成を始めない。試しに展開しても、通らなかった分岐の中の参照は見つからないためである（0004 設計への申し送り H-02）。検査の規則は [0004 設計書](../../tasks/0004_article_writer/02_architecture.md) の §3.4「テンプレートの検査（H-02・H-11）」と、prompts/README.md の「構築時に拒否されるテンプレート」にある。
-   **参照できる値は、テンプレートの組ごとのデータ型で決める。** 生成・字数の調整・検証・推敲の 3 組は、それぞれ別のデータ型で検査し、その型の値でしか展開できない。1 つのデータ型を共有すると、生成のテンプレートが生成の時点では空の本文を参照でき、字数の調整のテンプレートが字幕を LLM に渡せてしまうためである（[0010 設計書](../../tasks/0010_post_generation_review/02_architecture.md) §3.4）。組ごとに参照できる値は、[prompts/README.md](../../../prompts/README.md) の「参照できる値」とその後の 3 つの節に従う。
-   **テンプレートと展開したプロンプトの大きさに上限を置く。** 展開は上限付きの書き込み先に行い、上限を超えた展開は失敗させる。上限のない書き込み先に展開すると、長さを確かめる前にメモリを使い切りうるためである（0004 設計への申し送り H-11）。上限の値は [prompts/README.md](../../../prompts/README.md) の「上限」に従う。埋め込む値はテンプレートとして解釈せず、エスケープもしない。`html/template` を使うと HTML エスケープで字幕が変わるためである（0004 設計への申し送り H-03、0004 設計書 §3.6「プロンプトの展開と上限（F-003・H-10・H-11）」）。
-   **出典のリンクは、LLM の出力ではなくコードで付ける。** 出典の URL は検証した動画 ID から組み立て、生成したテキストの URL は使わない。出典のブロックは、生成・字数の調整・検証・推敲の工程がすべて終わった後に付ける。後の工程の LLM には出典のブロックを含まない本文を渡すので、どの工程の LLM も出典のブロックを書き換えられない。字幕・タイトル・概要欄へのプロンプトインジェクションで、出典が欠けたり別の URL に差し替えられたりしないためである（[0004 要件定義書](../../tasks/0004_article_writer/01_requirements.md) §1「概要」・F-006）。出典のブロックの形は 0004 設計書の §3.9「出典ブロック（F-006・H-05）」にある。工程の順序は [ADR-0002](0002-post-generation-steps.md) が定める。
-   **出典のブロックは、保存・ビューアでの表示・投稿のどれに使う記事にも付く。** 出典のブロックは記事の本文の一部であり、`--out` のファイル、サーバが返す表示用の Markdown、Webhook への投稿は、どれもこの本文から作る。記事の末尾には必ず元動画へのリンクを付けるためである（[project_overview.md](../project_overview.md)「前提・制約」）。信頼できないテキストの扱いの仕様の正本は [security.md](../security.md) の §6「信頼できないテキストの取り扱い」である。

ビューアが出典の自動リンクをリンクとして描画することは [ADR-0017](0017-viewer-markdown-rendering.md) が定める。

## 採らなかった案

-   **制御構造をすべて拒否し、`{{.Name}}` の形の参照だけを許す。** 構築時の検査を通り展開時に失敗するテンプレート（`{{index .Title 100}}`）を書けなくなり、概要欄の有無に応じた文面（`if`）も書けなくなる（[0004 設計書](../../tasks/0004_article_writer/02_architecture.md) §3.4「代替案」）。
-   **試しに展開して、参照できない値の参照を見つける。** 試しに使った値では通らない分岐の中の参照（`{{if .Description}}{{.APIKey}}{{end}}`）を見つけられない（[0004 設計への申し送り](../../tasks/0004_article_writer/design_handoff.md) H-02）。
-   **上限のない書き込み先に展開してから、長さを確かめる。** `{{printf "%1000000000s" .Title}}` のような記述で、長さを確かめる前にメモリを使い切る（[0004 設計への申し送り](../../tasks/0004_article_writer/design_handoff.md) H-11）。
-   **上限付きの書き込み先だけで大きさを抑え、`printf` などの関数を許す。** `printf` などの関数は結果の文字列を作り終えてから書き込むので、1 回の関数の呼び出しが作る文字列の大きさまでは抑えられない（[0004 設計への申し送り](../../tasks/0004_article_writer/design_handoff.md) H-11）。設計は、上限付きの書き込み先と、`print`・`printf`・`println` の構築時の拒否を組み合わせた（[0004 設計書](../../tasks/0004_article_writer/02_architecture.md) §3.4・§3.13）。
-   **構築時に、関数に渡す値の型も確かめる。** 値の型の推論は検査を複雑にする（[0004 設計書](../../tasks/0004_article_writer/02_architecture.md) §3.4）。字数の調整のテンプレートの数の値を加えたときも、型の合わない記述は上書きファイルを書く利用者の誤りなので、新たな検査は設けなかった（[0010 設計書](../../tasks/0010_post_generation_review/02_architecture.md) §3.4）。
-   **3 組のテンプレートで 1 つのデータ型を共有する。** 生成のテンプレートが、生成の時点では空の `.ArticleBody` を参照でき、字数の調整のテンプレートが `.Transcript` を参照して字幕を LLM に渡せてしまう（[0010 設計書](../../tasks/0010_post_generation_review/02_architecture.md) §3.4）。
-   **出典のリンクを LLM に書かせる。生成したテキストの URL を出典に使う。** 字幕・タイトル・概要欄へのプロンプトインジェクションで、生成結果が操作されうる（[0004 要件定義書](../../tasks/0004_article_writer/01_requirements.md) §1「概要」・F-006）。
-   **本文の末尾の改行の数に応じて、出典のブロックとの区切りを変える。** 区切りを常に `\n\n` にすれば、LLM の出力の中身によって組み立てを変える分岐が要らず、どの場合も出典のブロックの前に空行ができる（[0004 設計書](../../tasks/0004_article_writer/02_architecture.md) §3.9）。
-   **本文の末尾の改行を除いてから、出典のブロックを付け直す。** 記事の本文が LLM の書いた本文と同じ文字列で始まるという要件（AC-17）に反する（[0004 設計への申し送り](../../tasks/0004_article_writer/design_handoff.md) H-05）。
-   **出典のブロックの前に、区切りとして水平線（`---`）を置く。** 空行があれば出典のブロックは独立した段落になり、要件（AC-19）を満たす（[0004 設計書](../../tasks/0004_article_writer/02_architecture.md) §3.9）。
-   **出典の URL を `<` と `>` で囲まずに書く。** 囲まない URL は、CommonMark ではリンクにならない（[0004 設計書](../../tasks/0004_article_writer/02_architecture.md) §3.9）。

## 結果

-   CLI で上書きファイルを渡す利用者は、`with`・`range`・変数・`printf` などを使えない。これらを使うテンプレートは、参照できる値だけを使っていても拒否される。許可リストに構文や関数を足すときは、[prompts/README.md](../../../prompts/README.md) も同じ変更で直す（`TestPromptsREADMEMatchesContract` が、参照できる値・関数・上限を README とコードで照らす）。
-   値の型が合わない呼び出しと、値によって起きる失敗は、構築時ではなく展開時に見つかる。字数の調整と検証・推敲のテンプレートは生成の LLM を呼んだ後に展開するので、その失敗は生成の呼び出しを無駄にする（[0010 設計書](../../tasks/0010_post_generation_review/02_architecture.md) §3.4）。
-   引数の数とコマンドの形の検査は、セキュリティの要件ではなく、誤りを早く報告するためのものである。取りこぼしと過剰な拒否は、直す費用と利点を比べて扱う（[0004 設計書](../../tasks/0004_article_writer/02_architecture.md) §3.4）。
-   出典のブロックは、どの出力先の記事にも、LLM の出力によらず付く。字数の数え方は出典のブロックを除き、検証・推敲は出典のブロックを直さない。テンプレートの組を足すときは、データ型を分け、出典のブロックを含まない本文を渡す形を保つ。
-   コードは LLM が書いた本文を加工しないので、本文の中の URL や出典らしき行は、取り除かれずに出典のブロックの前に残る（[0004 設計書](../../tasks/0004_article_writer/02_architecture.md) §1.1・§3.9）。

## 経緯

- 2026-10-05 プロンプトのテンプレートを `text/template` で書き、使える構文を限って、規則に反するテンプレートを構築時に拒否することにした。出典のリンクは、検証した動画 ID からコードで組み立てて記事の末尾に付け、生成したテキストの URL を使わないことにした（[0004 要件定義書](../../tasks/0004_article_writer/01_requirements.md) §1「概要」・F-001・F-006）
- 2026-10-05 構文の検査を、解析木のノードの種類ごとの許可リストとし、許可リストにない種類を拒否することにした。上限付きの書き込み先と `print`・`printf`・`println` の拒否を組み合わせて展開の大きさを抑え、出典のブロックの書式を `出典: <URL>` の自動リンクと、本文との区切り `\n\n` に固定した（[0004 設計書](../../tasks/0004_article_writer/02_architecture.md) §1.1・§3.4・§3.6・§3.9）
- 2026-10-10 生成の後の字数の調整と検証・推敲のテンプレートにも、同じ検査の規則を当てはめた。参照できる値はテンプレートの組ごとのデータ型で分け、2 つの工程には出典のブロックを含まない本文を渡し、出典のブロックは最後の工程の後に付けることにした（[0010 設計書](../../tasks/0010_post_generation_review/02_architecture.md) §3.2・§3.4）
