# ADR-0016: ビューアは記事を自前の最小限のレンダラーで描画し、HTML を解釈せず、リンクは https の自動リンクだけにする

## 状態

| 項目 | 値 |
|---|---|
| 状態 | `有効` |

## 背景

ビューアは、サーバが返す記事（表示用の Markdown）を表示する拡張のページである。記事は LLM の出力で、字幕と動画メタデータを経由したプロンプトインジェクションで、意図しない HTML やリンクを含みうる。ビューアは `nativeMessaging` を呼べるので、記事からスクリプトが動けば、ホストへの任意の送信につながる（[security.md](../security.md) §8.1）。

拡張が出荷するのはこのリポジトリが書いたコードだけで、npm のパッケージは開発用に限るので（[CLAUDE.md](../../../CLAUDE.md)「Dependencies」）、Markdown のライブラリは使えない。0050 は、記事を Markdown として解釈せずに文字のまま表示し、描画を #504 に分けた（[0050 要件定義書](../../tasks/0050_viewer_tab/01_requirements.md) §1）。記事の書き方は生成のプロンプトが決め、レベル 1 とレベル 2 の見出し、段落、箇条書き、強調だけを使い、生の HTML と URL を書かない。

## 決定

-   **自前の最小限のレンダラーで描画する。** 扱う記法は、プロンプトが使う要素に限る。見出し（`#`・`##`）、段落、箇条書きと番号付きリスト（1 階層）、強い強調と強調、コードスパンとコードブロック、バックスラッシュのエスケープ、自動リンクである。
-   **記法は、要件定義書が定める単純な規則で解釈する。** CommonMark の解釈には合わせない。強調は 1 行の中の対になった記号だけで、入れ子にしない。
-   **扱わない記法と HTML は、要素にせず文字のまま表示する。** 生の HTML・HTML の文字参照・引用・表・水平線・入れ子のリスト・画像・`###` 以下の見出し・`[文字](URL)` のリンクは、記号を含めて文字として表示する。近い要素に直して描画することはしない。
-   **HTML を解釈しない。** DOM は要素の生成と文字列の設定だけで組み立てる。記事の内容から作る要素と属性は決めた一覧に限り、属性の名前を記事の内容から決めない。HTML を解釈する API の lint での禁止と、拡張のページの既定の Content Security Policy は変えない。
-   **リンクにするのは `https` の自動リンクだけにする。** `<https://…>` のうち、ホストを持ち、ユーザー名とパスワードを持たず、URL として解釈して文字列に戻したものと一致するものだけをリンクにする。表示する文字列とリンク先は、どちらもその URL の文字列である。リンクは新しいタブで、参照元を送らず、開いたページにビューアのウィンドウを渡さない形で開く。
-   **保存とコピーは描画の結果を使わない。** 状態の取得が返す文字列を変えずに保存し、コピーする。

この決定の仕様の正本は、[0063 要件定義書](../../tasks/0063_viewer_markdown/01_requirements.md) の 3.2 節「記法の規則」と F-003・F-004、および [security.md](../security.md) §8.1「ブラウザ拡張」である。

## 採らなかった案

-   **Markdown のライブラリを使う。** 拡張が出荷するのはこのリポジトリが書いたコードだけとする方針に反する（[0063 要件定義書](../../tasks/0063_viewer_markdown/01_requirements.md) §1）。
-   **引用・水平線・入れ子のリスト・`###` 以下の見出し、または表まで描画する。** プロンプトはこれらの記法を使わないので、扱ってもレンダラーとテストが増えるだけになる（[0063 要件定義書](../../tasks/0063_viewer_markdown/01_requirements.md) §1）。
-   **扱う要素について CommonMark と同じ構造に描画する。** 保存した `.md` を別のビューアで開いたときと表示がそろうが、強調の区切りの規則まで実装するとレンダラーとテストが大きくなる。記事はプロンプトが決めた単純な形なので、実用上の差は小さい（[0063 要件定義書](../../tasks/0063_viewer_markdown/01_requirements.md) §1）。
-   **`[文字](URL)` の形のリンクも `https` に限ってリンクにする。** 表示する文字列とリンク先が食い違いうる。プロンプトは URL を書かせないので、本文の中のリンクはプロンプトインジェクションの疑いが強い（[0063 要件定義書](../../tasks/0063_viewer_markdown/01_requirements.md) §1）。
-   **記事の中のリンクを、出典の URL も含めてリンクにしない。** 0050 の表示のままだが、出典の動画を開くのに URL の文字列のコピーが要る（[0063 要件定義書](../../tasks/0063_viewer_markdown/01_requirements.md) §1）。
-   **リンクを同じタブで開く。** ビューアのタブが遷移し、戻ると状態の取得からやり直しになる（[0063 要件定義書](../../tasks/0063_viewer_markdown/01_requirements.md) §1）。

## 結果

-   記事が `https` の自動リンクで任意のサイトを指すことは防がない。リンクの表示は URL そのもので、参照元とビューアのウィンドウは渡らない。
-   保存した `.md` を CommonMark のビューアで開くと、ビューアの表示と細部が異なりうる（段落の中の改行など）。
-   プロンプトが新しい記法を使うようになっても、レンダラーを変えるまでは、その記法は文字のまま表示される。扱う記法を増やすタスクは、この ADR を更新する。
-   レンダラーは表示用の Markdown の中身を調べて描画する要素を選ぶので、CLAUDE.md「Declare, don't infer」の例外になる。例外の範囲はレンダラーの解釈に限る。

## 経緯

- 2026-11-05 ビューアは記事を自前の最小限のレンダラーで描画し、扱う記法をプロンプトが使う要素に限り、記法を単純な規則で解釈し、HTML を解釈せず、リンクは `https` の自動リンクだけを新しいタブで参照元を送らずに開くことにした（[0063 要件定義書](../../tasks/0063_viewer_markdown/01_requirements.md) §1）
